Ghostty 使用笔记：macOS 快捷键与配置

发表于 2026-11-02 分类于 工具与效率 阅读次数：
本文字数： 3.6k 阅读时长 ≈ 4 分钟

整理 Ghostty 在 macOS 上的常用快捷键和配置方法。

下面的快捷键按 macOS 版 Ghostty 1.4.0 的默认设置整理。如果改过键位，可以运行 ghostty +list-keybinds 查看当前绑定。

符号说明：⌘ = Command，⌥ = Option / Alt，⌃ = Control，⇧ = Shift。加号表示同时按下；配置里的 super、cmd 都表示 macOS 的 Command。

忘记快捷键时，先按 ⌘ + ⇧ + P 打开命令面板，搜索操作名称。最常用的工作流是：⌘T 开标签页，⌘D 开右侧分屏，⌘⌥方向键 切换分屏，⌘⇧Enter 临时放大。

窗口与标签页

操作 快捷键 说明
新建窗口 ⌘ + N 独立窗口，适合不同任务或显示器。
新建标签页 ⌘ + T 同一窗口内组织不同项目。
上一个标签页 ⌃ + ⇧ + Tab 也可以使用 ⌘ + ⇧ + [。
下一个标签页 ⌃ + Tab 也可以使用 ⌘ + ⇧ + ]。
跳到第 1～8 个标签页 ⌘ + 1 … 8 按标签页顺序直接定位。
跳到最后一个标签页 ⌘ + 9 注意：表示最后一个，而非固定第九个。
关闭当前终端 ⌘ + W 有分屏时关闭当前分屏；关闭最后一个终端时，标签页也会关闭。
关闭当前标签页 ⌘ + ⌥ + W 关闭该标签页及其中所有分屏。
关闭当前窗口 ⌘ + ⇧ + W 包括窗口内所有标签页和分屏。
退出 Ghostty ⌘ + Q 退出整个应用。
切换全屏 ⌘ + ⌃ + F 默认也绑定了 ⌘ + Enter。
撤销支持的界面操作 ⌘ + Z 也可用 ⌘ + ⇧ + T，例如在有效时间内恢复关闭的终端。
重做界面操作 ⌘ + ⇧ + Z 只适用于 Ghostty 支持撤销的操作。

关闭时是否弹出确认取决于配置、正在运行的程序和 Shell Integration。撤销受 undo-timeout 限制，不会撤销 Shell 命令或文件修改。

分屏：创建、切换与调整

操作 快捷键 说明
向右分屏 ⌘ + D 新增一个右侧终端，形成左右布局。
向下分屏 ⌘ + ⇧ + D 新增一个下方终端，形成上下布局。
切到指定方向的分屏 ⌘ + ⌥ + 方向键 按上、下、左、右选择相邻终端。
切到上一个分屏 ⌘ + [ 按分屏顺序切换。
切到下一个分屏 ⌘ + ] 与加 Shift 后的标签页切换区分。
放大 / 还原当前分屏 ⌘ + ⇧ + Enter 让当前分屏占满标签页，再按一次恢复布局。
调整分屏尺寸 ⌘ + ⌃ + 方向键 向指定方向调整，每次 10 像素。
均分分屏尺寸 ⌘ + ⌃ + = 恢复均衡布局。

日常开发可以左侧编辑、右上运行命令、右下看日志。需要集中阅读时临时放大一个分屏；不必为了放大而关闭其他终端。

搜索、滚动与命令输出

操作 快捷键 说明
搜索终端内容 ⌘ + F 搜索当前终端保留的内容。
搜索当前选中文本 ⌘ + E 先选中报错、路径或关键词。
下一个搜索结果 ⌘ + G 需要已激活搜索。
上一个搜索结果 ⌘ + ⇧ + G 需要已激活搜索。
关闭搜索 Esc 默认也可用 ⌘ + ⇧ + F。
向上 / 向下翻页 ⌘ + Page Up / Page Down 滚动终端回滚区。
滚到顶部 / 底部 ⌘ + Home / End 紧凑键盘通常可用 Fn 配合方向键产生这些键。
上一个 / 下一个命令提示符 ⌘ + ↑ / ↓ 也可加 Shift；依赖提示符标记与 Shell Integration。
滚到选区 ⌘ + J 快速回到当前选中的文本位置。
清空屏幕与回滚内容 ⌘ + K 会清除终端的历史输出，先保存需要的日志。
将当前屏幕内容写入临时文件并粘贴路径 ⌘ + ⇧ + J 导出当前屏幕，不等同于导出全部回滚历史。
将当前屏幕内容写入临时文件并复制路径 ⌘ + ⌃ + ⇧ + J 复制的是文件路径，方便交给其他工具。
用默认程序打开当前屏幕导出文件 ⌘ + ⌥ + ⇧ + J 便于在编辑器中继续查看。

搜索不会恢复已经超出回滚限制的输出。需要长期保存的日志，优先在运行命令时写入文件。⌘K 与 Shell 常用的 ⌃L 行为不同：前者会清除回滚内容。

复制粘贴、选择与字体

操作 快捷键 说明
复制选中文本 ⌘ + C 终端内中断程序通常使用 ⌃ + C。
粘贴 ⌘ + V 多行命令粘贴前先检查内容。
全选 ⌘ + A 选择当前终端内容。
调整已有选区 ⇧ + 方向键 用于扩展或收缩现有文本选择。
增大字体 ⌘ + = 默认也接受 ⌘ + +。
缩小字体 ⌘ + - 调整显示字号。
恢复配置中的字号 ⌘ + 0 回到 font-size 指定的大小。

启用 Shell Integration 后，还可以按住 ⌘ 三击，选中一条命令的输出；在提示符处 ⌥ + 单击 可以移动输入光标。是否可用取决于 Shell 与提示符集成。

配置管理：先查看默认值，再做小幅定制

操作 快捷键 说明
打开配置文件 ⌘ + , 使用系统配置的编辑程序打开。
重新加载配置 ⌘ + ⇧ + , 部分设置只对新终端生效，或需要重启应用。
命令面板 ⌘ + ⇧ + P 搜索操作并查看当前绑定的快捷键。
终端检查器 ⌘ + ⌥ + I 排查按键、渲染和终端行为。

先记录本机版本和键位。带 --default 的命令列出默认绑定，不带该参数则列出加载当前配置后的绑定；它们不包含操作系统拦截的快捷键。

如果提示 command not found: ghostty，macOS 默认安装位置可直接使用下面的可执行文件，不必为了查阅文档修改 Shell 配置：

当前版本配置文件推荐使用 config.ghostty，旧文件名 config 仍受支持。默认路径包括：

  • 通用路径：~/.config/ghostty/config.ghostty；若设置了 XDG_CONFIG_HOME，则使用对应目录。
  • macOS 路径：~/Library/Application Support/com.mitchellh.ghostty/config.ghostty。

macOS 路径中的配置在 XDG 路径之后加载，同名设置可能覆盖前面的值。日常维护一个主要配置文件更容易排查。通过 ⌘, 打开配置，比凭记忆猜路径更方便。

全局快速终端绑定需要给 Ghostty 辅助功能权限；若该组合已被系统或其他应用占用，请换一组。配置写法是 keybind = 按键=动作，例如 keybind = cmd+d=new_split:right。保留默认绑定，只补充常用操作，后续维护会更轻松。

修改后先运行 ghostty +validate-config，再按 ⌘⇧, 重载。若操作不符合预期，查看命令面板和当前 +list-keybinds 输出。

补充：Shell 常用按键

下面属于 Shell / 终端程序的常见按键约定，不是 Ghostty 的界面快捷键。行编辑行为以 zsh / bash 的 Emacs 键位为例，Vi 模式、tmux 和其他程序可能不同。

操作 快捷键 说明
中断前台程序 ⌃ + C 向前台任务发送中断信号，程序可以自行处理。
搜索命令历史 ⌃ + R 由 Shell 或历史搜索插件处理。
移到行首 / 行尾 ⌃ + A / E 编辑当前输入的命令。
删除光标前的一个单词 ⌃ + W 由 Shell 行编辑模式决定。
删除光标前到行首的内容 ⌃ + U 适合重新输入一条命令。
重绘 / 清理当前显示 ⌃ + L 常见 Shell 行编辑行为，通常保留回滚历史。

不要把 ⌃D 当作分屏快捷键：它通常表示输入结束，在空提示符处可能退出 Shell。Ghostty 的向右分屏是 ⌘D。

日常使用习惯

  1. **按项目分标签页，按任务分分屏。**同一项目的编辑、构建、日志放在一个标签页，避免开太多难以辨认的窗口。
  2. **先记住高频操作。**新建标签、左右分屏、分屏切换、临时放大、搜索、重载配置这几组足以覆盖多数开发场景。
  3. **保留 Shell Integration。**Ghostty 支持为 zsh 等 Shell 自动注入集成；目录继承和提示符跳转不工作时，先检查集成与提示符插件。
  4. **需要持久会话时配合 tmux。**尤其是远程 SSH 长任务，把任务放在 tmux 会话中，断线后可以重新连接。Ghostty 的标签页和分屏用于本机组织界面。
  5. **升级后重新核对。**记录 ghostty --version 与默认键位，及时更新本页；自定义配置与默认键位分别维护。
