Ghostty 使用笔记：macOS 快捷键与配置

发表于 2026-11-02 分类于 工具与效率 阅读次数：
本文字数： 3k 阅读时长 ≈ 3 分钟

整理 Ghostty 在 macOS 上的常用快捷键和配置方法。

下面的快捷键按 macOS 版 Ghostty 1.4.0 的默认设置整理。如果改过键位，可以运行 ghostty +list-keybinds 查看当前绑定。

符号说明：⌘ = Command，⌥ = Option / Alt，⌃ = Control，⇧ = Shift。加号表示同时按下；配置里的 super、cmd 都表示 macOS 的 Command。

忘记快捷键时，可以按 ⌘ + ⇧ + P 打开命令面板，按操作名称搜索。

窗口与标签页

操作 快捷键 说明
新建窗口 ⌘ + N
新建标签页 ⌘ + T
上一个标签页 ⌃ + ⇧ + Tab 也可以使用 ⌘ + ⇧ + [。
下一个标签页 ⌃ + Tab 也可以使用 ⌘ + ⇧ + ]。
跳到第 1～8 个标签页 ⌘ + 1 … 8
跳到最后一个标签页 ⌘ + 9 无论有多少个标签页，都会跳到最后一个。
关闭当前终端 ⌘ + W 有分屏时只关闭当前分屏；关闭最后一个分屏时，标签页也会关闭。
关闭当前标签页 ⌘ + ⌥ + W 关闭该标签页及其中所有分屏。
关闭当前窗口 ⌘ + ⇧ + W 包括窗口内所有标签页和分屏。
退出 Ghostty ⌘ + Q
切换全屏 ⌘ + ⌃ + F 也可用 ⌘ + Enter。
撤销界面操作 ⌘ + Z 也可用 ⌘ + ⇧ + T，可恢复刚关闭的分屏、标签页或窗口。
重做界面操作 ⌘ + ⇧ + Z

关闭终端时是否弹出确认，与配置、运行中的程序和 Shell Integration 有关。界面操作只能在 undo-timeout 设置的时间内撤销；这里的撤销不影响 Shell 命令或文件修改。

分屏操作

操作 快捷键 说明
向右分屏 ⌘ + D 左右布局。
向下分屏 ⌘ + ⇧ + D 上下布局。
切到相邻分屏 ⌘ + ⌥ + 方向键
切到上一个分屏 ⌘ + [ 加上 ⇧ 则切换标签页。
切到下一个分屏 ⌘ + ] 加上 ⇧ 则切换标签页。
放大 / 还原当前分屏 ⌘ + ⇧ + Enter 让当前分屏占满标签页，再按一次恢复布局。
调整分屏尺寸 ⌘ + ⌃ + 方向键 向指定方向调整，每次 10 像素。
均分分屏尺寸 ⌘ + ⌃ + =

可以为每个项目开一个标签页，再把编辑、构建和日志放在不同分屏里。例如左侧编辑代码，右上运行命令，右下查看日志。阅读日志时，按 ⌘ + ⇧ + Enter 放大当前分屏，再按一次恢复布局。

搜索与滚动

操作 快捷键 说明
搜索终端内容 ⌘ + F
搜索选中文本 ⌘ + E 可先选中报错、路径或关键词。
下一个搜索结果 ⌘ + G 搜索时可用。
上一个搜索结果 ⌘ + ⇧ + G 搜索时可用。
关闭搜索 Esc 也可用 ⌘ + ⇧ + F。
向上 / 向下翻页 ⌘ + Page Up / Page Down
滚到顶部 / 底部 ⌘ + Home / End 紧凑键盘通常可用 Fn 配合方向键输入这些键。
跳到上一个 / 下一个提示符 ⌘ + ↑ / ↓ 也可加 ⇧；需要 Shell Integration 提供提示符标记。
滚到选区 ⌘ + J 回到选中文本的位置。
清空屏幕与回滚内容 ⌘ + K 清除后无法再通过滚动查看之前的输出。
导出屏幕并粘贴路径 ⌘ + ⇧ + J 将当前屏幕写入临时文件，向终端粘贴文件路径。
导出屏幕并复制路径 ⌘ + ⌃ + ⇧ + J 将当前屏幕写入临时文件，向剪贴板复制文件路径。
导出屏幕并打开文件 ⌘ + ⌥ + ⇧ + J 将当前屏幕写入临时文件，用系统默认程序打开。

搜索范围限于终端仍保留的内容，屏幕导出也只包含当前屏幕。需要完整保存日志时，可以在运行命令时将输出写入文件。

⌘ + K 会清除回滚内容；Shell 中常用的 ⌃ + L 通常只清理当前显示，仍能向上滚动查看历史输出。

文本操作与字体

操作 快捷键 说明
复制选中文本 ⌘ + C 终端内中断程序通常使用 ⌃ + C。
粘贴 ⌘ + V
全选 ⌘ + A
调整选区 ⇧ + 方向键 需先选中文本，再扩展或收缩选区。
增大字体 ⌘ + = 默认也接受 ⌘ + +。
缩小字体 ⌘ + -
恢复默认字号 ⌘ + 0 恢复为配置中 font-size 指定的大小。

启用 Shell Integration 后，按住 ⌘ 连点三次可以选中一条命令的输出；在提示符处按住 ⌥ 单击，可以把输入光标移到点击位置。

配置文件位置

配置文件使用 config.ghostty，旧文件名 config 也仍然可用。默认读取以下位置：

  • 通用路径：~/.config/ghostty/config.ghostty。设置了 XDG_CONFIG_HOME 时，改为 $XDG_CONFIG_HOME/ghostty/config.ghostty。
  • macOS 路径：~/Library/Application Support/com.mitchellh.ghostty/config.ghostty。

两处都有配置时，先读取通用路径，再读取 macOS 路径；后加载的同名设置会覆盖前面的值。

Shell 常用按键

下面这些按键由 Shell 或终端程序处理。行编辑以 zsh / bash 的 Emacs 键位为例，使用 Vi 模式、tmux 或其他程序时，行为可能不同。

操作 快捷键 说明
中断前台程序 ⌃ + C 发送中断信号，程序可以自行处理。
搜索命令历史 ⌃ + R 可能由历史搜索插件接管。
移到行首 / 行尾 ⌃ + A / E
删除光标前的一个单词 ⌃ + W
删除光标前到行首的内容 ⌃ + U
清理当前显示 ⌃ + L 通常保留回滚历史。

⌃ + D 通常表示输入结束，在空提示符处可能退出 Shell；向右分屏使用的是 ⌘ + D。
