本文将介绍如何在centos系统通过源码安装python。

本文记录 2023 年安装 Python 3.12.0 的流程，当时没有记下具体的 CentOS 版本。示例中的 OpenSSL 1.1.1o 已停止上游公共维护，新部署请选择仍受支持的系统、Python 和 OpenSSL 版本组合。

Python 3.10 及以上要求 OpenSSL 至少为 1.1.1，而不同 CentOS 版本自带的 OpenSSL 也不同，需要先检查本机环境。下面将 OpenSSL 和 Python 安装到独立目录，保留系统原有的程序和库。

安装独立的openssl

先准备 C 编译器、make 及目标 Python 所需的开发库；具体软件包名随 CentOS 版本变化。Python 3.12 要求支持 C11 的编译器，可按 Python 构建要求 检查环境。
